## Gotchas found (each with its triggering error text)

- `unknown flag: --progress` — distro docker.io 27.5.1 (image-bundled!) or any `DOCKER_BUILDKIT=0`.
- `fatal: $HOME not set` on `git lfs install` — GCE startup scripts run root w/o HOME.
- `Could not fetch serial port output: … is not ready` — instance TERMINATED; recovery recipe in README ("Postmortem: reading the log of a TERMINATED VM").
- `ssh: connect to host … port 22: Operation timed out` — no TCP-22 path from this network to this project; do NOT design around `gcloud compute ssh`.
- gcloud `--boot-disk-size 20` = 20 **MB**; driver passes `${DISK_GB}GB` + `--boot-disk-auto-delete` (manual.md's own example bites).
- Disk attach race: `The disk resource … is already being used by …` right after `instances stop` — poll `disks describe --format 'value(users)'` first.
- Correction shouted: README/CLAUDE previously claimed Cloud Build is blocked by `--squash`; modern engines accept it as a no-op — README rewritten (blockers now: unmanaged daemon.json, GitHub App, docs-dropped custom workers).
